# OlapTradesLeaderboardSourceGroup

Source group:
  * `RARIBLE` - source group includes rarible sources (rarible.com + all communities)
  * `EXTERNAL` - source group includes external marketplaces as sources


## Example Usage

```typescript
import { OlapTradesLeaderboardSourceGroup } from "@rarible/protocol-mcp";

let value: OlapTradesLeaderboardSourceGroup = "RARIBLE";
```

## Values

```typescript
"RARIBLE" | "EXTERNAL"
```
