# SignatureInputForm

Form contains required data to generate input message for signing. All fields should be specified in 'native' manner, i.e. without BLOCKCHAIN prefixes


## Supported Types

### `models.OpenSeaFillOrderSignatureInputForm`

```typescript
const value: models.OpenSeaFillOrderSignatureInputForm = {
  signature:
    "0xf3104d38a35c59d2612a6128c9e2bbfabf16f26b2db393801cc20398f10079f2",
  blockchain: "ETHEREUM",
};
```
