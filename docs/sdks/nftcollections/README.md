# NFTCollections
(*nftCollections*)

## Overview

### Available Operations

* [getCollectionById](#getcollectionbyid) - Get NFT Collection by Id
* [generateTokenId](#generatetokenid) - Generate TokenId

* [resetCollectionMeta](#resetcollectionmeta) - Reset Collection metadata
* [getCollectionsByOwner](#getcollectionsbyowner) - Get NFT Collections owned by user
* [getAllCollections](#getallcollections) - Get all NFT Collections
